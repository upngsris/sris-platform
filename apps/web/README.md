# SRIS Homepage Visual Prototype v1

Static visual prototype for the SRIS homepage.

## Stack
- Next.js 16 App Router
- TypeScript
- Tailwind CSS v4
- Geist + Inter via next/font

## Install
Copy the supplied folders into an existing Next.js 16 project with Tailwind CSS v4 configured.

The prototype intentionally contains:
- no Sanity queries
- no PostgreSQL/Prisma
- no authentication
- no external photography
- static placeholder data

Review at approximately 1440px desktop and 390px mobile before connecting CMS/backend systems.
